# Product

## Register

product

## Users

Arabic-speaking For You Shoe owners and store staff use this dashboard on desktop and mobile to monitor Shopify orders, send WhatsApp confirmations, review customer responses, and diagnose delivery failures.

## Product Purpose

Connect Shopify orders to WhatsApp reliably. Success means an operator can understand connection health, confirm that new orders are being processed, resend when necessary, and identify failures without navigating a technical setup wizard.

## Brand Personality

Calm, trustworthy, efficient. The interface should feel operational and reassuring while keeping technical detail available when it is useful.

## Anti-references

Avoid a card-heavy setup wizard, arbitrary numbering, decorative dashboard clutter, excessive technical copy, and dark styling that makes routine daytime work feel like an incident console.

## Design Principles

1. Lead with operational status and the next useful action.
2. Keep routine order work separate from infrequent integration settings.
3. Reveal technical detail progressively instead of presenting everything at once.
4. Make success, pending work, and failure states unmistakable without relying on color alone.
5. Preserve Arabic-first clarity while displaying identifiers and API values in the correct direction.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support RTL-first reading, keyboard navigation, visible focus, adequate touch targets, responsive desktop and mobile layouts, color-independent status cues, and reduced-motion preferences.
